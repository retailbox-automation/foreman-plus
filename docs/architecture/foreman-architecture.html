Foreman+ — gated multi-agent memory for HVAC field techs

Photo / voice / text intake — from the technician's phone (/tech) or glasses — routes through an ADK agent fleet on Cloud Run. Every write to shared fleet memory passes one gate — identity, caps, an advisory lock, and a Gemini verifier — before it lands in Postgres. The closer agent doubles as a CRM-agnostic A2A service; the office seat (/) derives property records from the same gated facts, every one tagged with its source; a Firestore feed gives live visibility.
