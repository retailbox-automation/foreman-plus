## Системная критика opus-судьи (важнее скоров)
«Ни один из восьми В ТЕКУЩЕМ ВИДЕ не берёт Grand Prize»: (1) топология 4-5 агентов против 34 у эталонного победителя SalesShortcut; (2) 5-6 Google-продуктов против 8-9; (3) никто не трогает реальный governance-surface; (4) у 5 из 8 концептов recycled-подпись write-gate (наш же FleetMemory-механизм в новой обёртке — судья, видевший обе заявки, это заметит).

## Рекомендация: «Foreman+» — Foreman, усиленный по всем осям критики
Ядро (единогласный №1): техник field-service компании снимает фото объекта + наговаривает голосом → флот агентов сам: понимает работу (мультимодальный Gemini — честный Google-native дифференциатор, недоступный Claude/GPT-конкурентам), подбирает материалы/цены (semantic lookup прайсбука), считает выезд (Maps), собирает квоту, **автономно отправляет** мелкие (< порога) и поднимает человеку крупные (governance-гейт по $-порогу = autonomous execution + управляемость), букает слот (Calendar), шлёт follow-up/reminder цепочку.
Усиления против критики:
1. **Топология**: не 5 агентов, а полноценный флот 10-15 специализированных (intake/vision/scope/parts/pricing/travel/quote-composer/dispatcher/scheduler/follow-up/collections + verifier + observability) с Sequential/Parallel/Loop узлами ADK — метрика топологии в README как у SalesShortcut.
2. **Google-продукты (8-9)**: Gemini 3.6 Flash (мультимодал) · ADK · Cloud Run · Cloud SQL+pgvector · Firestore · Pub/Sub · Maps API · Calendar/Gmail API · Vertex embeddings (+Gemma-классификатор = бонус-модель).
3. **Автономность (ответ судье-3)**: threshold-gate — квоты до $N уходят клиенту БЕЗ человека (в демо видно «sent» без клика), выше $N — один тап. Это одновременно закрывает «черновик для человека» и даёт governance-стори без копии FleetMemory-верифаера.
4. **Наша правда**: field services = наша реальная клиентская вертикаль в проде (flooring, plumbing, HVAC-cohort) — Real-World Impact секция будет честной, с обезличенной фактурой боли.
5. Recycled-риск у Foreman минимален из топ-3: механизм-звезда — мультимодальность, не write-gate.
Трек при сабмите: Taskmaster (workflow, not chatbot) или Startup Excellence — решить при сабмите, Grand Prize судится поверх.
