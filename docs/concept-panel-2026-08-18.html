Рекомендация по треку: Startup Excellence

  • Почему: тот же номинал $20k, что у Taskmaster/Fleet, но пул отфильтрован incorporation-требованием — большинство из 4,862 участников (студенты, соло-хоббисты) туда физически не могут подать. Лучшее соотношение приз/конкуренция.
  • Наша стори непобиваемо честная: инкорпорированное агентство, которое УЖЕ автоматизирует field-service бизнесы в проде, выводит продукт для своей вертикали. У хоббистов такого нарратива нет.
  • Ничего не теряем на Grand Prize: гранд судится по общему rubric (40/30/30) поверх категорий. Fleet-качества (registry, guardrails/Model Armor, OTel-observability) всё равно строим — они дают Architecture-30% в любом треке, а после опенсорс-скана стоят дёшево.
  • Trade-off честно: в Startup-треке средний конкурент сильнее (реальные стартапы с полишем). Если хочется максимального дескриптивного совпадения с текстом трека — Taskmaster, но там самая большая толпа.
  • Когда Fleet был бы правильным: если повернуть стори с «один техник» на «флот на компанию с N техников + governance» и быть готовыми показать КАЖДЫЙ пункт чеклиста. Это +1-2 дня работы на Identity/Gateway-слой сверх плана.

Все 8 концептов подробно

🥇 #4 Foreman 4.12 · №1 единогласно Feas 3.0

Фото + голос техника с объекта → флот сам собирает, ценит и отправляет клиенту квоту — офис-админ не нужен.
СториТехник заканчивает осмотр → фото проблемы + 10-сек голосовая заметка. Vision-Estimator читает обе модальности одним нативным вызовом Gemini → структурированный скоуп работы. Параллельно: Pricer (semantic-поиск по прайсбуку — «leaking tank» находит нужный SKU без точных слов), Scheduler (реальный календарь). Quote-Writer собирает itemized-квоту, Verifier проверяет маржу/аномалии — и клиент получает цену, пока конкурент ещё едет в офис писать заметки.
Wow первых 30 сек: фото протекающего водогрея + голос «клиент хочет замену» → топология зажигается узел за узлом → готовая квота-PDF со слотом визита. Ни одной формы, ни одного напечатанного слова.
За: мультимодальность = честный Google-native дифференциатор (Claude/GPT-конкурентам недоступен) · сильнейший grandma-test · боль реальна (скорость квоты = выигранная работа) · field services = наша прод-вертикаль.
Против (судьи): двойной незнакомый риск — мультимодал-вайринг + Calendar OAuth при нуле GCP; не заспайкано в день 1-2 → демо рушится целиком. Опус: «итог — черновик квоты, техник жмёт send» → автономность дожать $-порогом (фикс в Foreman+).

#7 Handoff 3.75 Feas 4.0 recycled-риск MAX

Транскрипт встречи входит — реальные события Calendar, CRM-записи и письма выходят; верифаер ветирует всё, чего не было сказано.
СториExtractor тянет обязательства (даты, цены, деливераблы) → Scheduler создаёт реальный Calendar-холд, CRM-writer пишет запись, Emailer драфтит follow-up. Verifier сверяет каждую запись с транскриптом ДО коммита — выдуманная цена блокируется с красным REJECTED.
Wow: кликабельное событие в Calendar за секунды; четвёртое «обязательство» (цены не было в транскрипте) — верифаер краснеет, ничего не записано.
Против (все трое): REJECTED-кульминация дословно повторяет FleetMemory — тот же автор, тот же месяц, публичный репо. Судья, видевший обе заявки, прочитает как перекраску.

#1 DeskZero 3.60 Feas 4.0 — самый безопасный

Любой чек/инвойс/накладная — принят, прочитан, сверен и заведён в бухгалтерию без единого ручного клика.
СториIntake (почта/аплоад) → Vision (Gemini читает кривое фото) → Reconciliation (векторный поиск дублей/аномалий по истории трат) → Ledger (сам заводит запись) → Escalation (решает: закрыть тихо или поднять человеку с обоснованием).
Wow: судья фоткает мятый чек → флот находит дубль трёхдневной давности и сам отклоняет повтор с объяснением.
Против: самый насыщенный жанр из всех — «фото чека» есть на каждом мультимодальном хакатоне, это буквально Google-codelab с Document AI → Innovation (40% веса) проседает. Роль: фоллбэк, если спайк Foreman провалится.

#3 Baton 3.60 Feas 2–3.5

«Deal Won» → эстафета через 5 независимых Cloud Run агентов по A2A: контракт → инвойс → коллекшн → retention, governance-гейт на каждом денежном действии.
СториCloser (термы→контракт-драфт) ∥ Biller (инвойс+пейлинк) → Collector (сам ведёт цепочку напоминаний по срокам) → Retention (сигналы оттока + save-play). Verifier гейтит каждое внешнее действие: мелочь auto-approve, крупное — один тап человека. Не чатбот: человек с системой не разговаривает вообще.
Wow: одна кнопка «Deal Won — $18,000» → топология зажигается по узлам → кликабельный инвойс-линк за 20 сек.
Против (опус): 5 сервисов + A2A + Pub/Sub при нуле GCP = вся стройка уйдёт в деплой-механику; демо-итог — мокнутый инвойс и неотправленный контракт, wow = анимация, а не проверяемый артефакт.

#6 ShelfSense 3.47 Feas 2–3.5

Запасы независимого ритейлера под управлением «невидимого COO»: сам прогнозирует, сам сравнивает поставщиков, сам заказывает — до того, как товар кончился.
СториForecast (stockout за N дней по сезонности) → Sourcing (сравнение прайсов поставщиков) → Negotiation (письмо с торгом за объёмную скидку) → Budget-guardian (auto-approve в рамках лимита, иначе эскалация «подпишите одним кликом») → Tracking. Целился ровно в Fortified Enterprise Fleet трек (Identity/Gateway/Observability по учебнику).
Wow: полка корма визуально тает → красный «stock out in 4 days» → карточки трёх поставщиков → Negotiation печатает письмо на глазах → зелёный «auto-approved: $340, within policy».
Против (опус): мир полностью синтетический (сгенерированные продажи + стаб-поставщики) — «симуляция бизнеса, а не система в нём»; судья на Q&A обесценит Utility (40%).

#5 PermitPilot 3.35 Feas 2.0

Флот проводит малый подряд через ад городских разрешений — от чертежа до инспекции — без единого звонка в мэрию.
СториIntake (адрес+тип работ голосом) → Jurisdiction (определяет коды/формы конкретного округа, парсит муниципальные сайты) → Filing (заполняет пакет) → Tracking (поллит портал) → Response (сам отвечает на «revision requested») → Scheduling (бронь инспекции).
Против: слабейшая реализуемость — парсинг разношёрстных гос-сайтов за 13 дней при нуле GCP; реальная подача в гос-порталы = антибот + юридически серая зона ⇒ половина топологии в демо — декорация в staging-режиме.

#8 Ledger 3.20 Feas 4.0

Следит за дрейфом часов/скоупа против контракта в реальном времени — и не алертит, а блокирует плохой инвойс и сам драфтит change-order.
СториКонтракт + живой тайм-лог (Google Sheet без миграции) → Watcher ловит дрейф в момент появления → Guardian физически останавливает in-flight инвойс до подписи человеком → Drafter пишет change-order и сообщение клиенту голосом фаундера (few-shot).
Wow: метр скоупа ползёт за 100% на глазах → Guardian СТОПит инвойс красным блоком → готовое сообщение клиенту.
Против: узкая аудитория (fixed-price фрилансеры — судья боль не узнает); «автономность» = блокировка собственного же мока, наружу не происходит ничего — слабейший autonomous execution в выборке.

#2 Aftermath 3.03 — худший Feas 4.2

Звонок закончился — а календарь, письма и CRM уже обновлены, пока люди прощаются.
СториДвойник Handoff от другого генератора: транскрипт → извлечение договорённостей → исполнение через Workspace API с одним approve-гейтом на письмо.
Против: конкурирует с шипнутым продуктом самого спонсора — Gemini в Meet уже делает follow-ups и action items («зачем это отдельный проект?»); топ-1 по затоптанности жанр (Otter/Fireflies/Fathom + сто клонов); внутренний дубль #7.
